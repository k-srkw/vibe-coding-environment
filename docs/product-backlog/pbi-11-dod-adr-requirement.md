# PBI-11: DoD に ADR 要否判断の記録を必須化

## ステータス: 未着手

## 依存

## 説明

レトロスペクティブで PBI-5, PBI-6 が ADR 要否判断を明示的に記録していなかったことが指摘された。DoD の ADR セクション（セクション 7）を強化し、ADR を作成しない場合でも「検討した結果不要と判断した」旨を完了証跡に記録することを必須化する。

- [ ] `definition-of-done.md` の ADR セクションに「ADR 要否の判断理由を完了証跡に記載する」ルールが追加されている

- [ ] PBI テンプレートの完了証跡セクションに ADR 要否の記載欄がある
