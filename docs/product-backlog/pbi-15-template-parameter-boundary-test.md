# PBI-15: テンプレートパラメータ境界値テスト

## ステータス: 未着手

## 依存

- なし

## 説明

レトロスペクティブでテンプレートパラメータ（プロジェクト名、オーナー、リポジトリ名）の境界値テストが不足していることが指摘された。空文字、特殊文字、日本語、長い文字列などのエッジケースで Scaffolder が正しく動作するか（またはエラーを返すか）を Scenario Outline で検証する。

## 受け入れ条件

- [ ] テンプレートパラメータの境界値を検証する Gherkin シナリオが Scenario Outline で作成されている
- [ ] 正常系（有効なパラメータ）と異常系（無効なパラメータ）の両方がテストされている
- [ ] テンプレート側でパラメータバリデーションが適切に設定されている
- [ ] 全テストが Green である
