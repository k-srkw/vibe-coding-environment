# PBI-16: 生成プロジェクトの動的行動テスト強化

## ステータス: 未着手

## 依存

- なし

## 説明

レトロスペクティブでテストの 77% が構造検証（ファイル存在・静的内容検査）に偏っており、動的行動テストが 23% に留まっていることが指摘された。生成されたプロジェクトが実際に機能することを検証する動的テストを追加する。

具体的には:
- 生成プロジェクトの TypeScript コンパイル（`tsc --noEmit`）の検証
- `catalog-info.yaml` のレンダリング結果が有効な Backstage カタログ YAML であることの検証
- skeleton のネガティブテスト（意図的にファイルを壊した場合のエラーハンドリング）

## 受け入れ条件

- [ ] skeleton を展開した環境で TypeScript コンパイルが成功することを検証するテストがある
- [ ] `catalog-info.yaml` のテンプレート変数置換後の内容が有効な YAML であることを検証するテストがある
- [ ] skeleton のネガティブテスト（ファイル欠損時のエラー検出）がある
- [ ] 全テストが Green である
