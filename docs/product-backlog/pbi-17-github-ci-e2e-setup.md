# PBI-17: @github テストの CI 実行環境整備

## ステータス: 未着手

## 依存

- なし

## 説明

レトロスペクティブで E2E 統合テスト（`@github` タグ）が `GITHUB_TOKEN` 未設定時にスキップされ、最も価値の高いテストが最も実行されにくい構造になっていることが指摘された。CI パイプライン（GitHub Actions）で `GITHUB_TOKEN` を secret として設定し、PR マージ前に E2E テストが自動実行される環境を整備する。

## 受け入れ条件

- [ ] 本リポジトリの GitHub Actions CI ワークフローに `GITHUB_TOKEN` secret を利用したテスト実行ステップがある
- [ ] `@github` テストが CI で実行され、結果が PR に表示される
- [ ] テスト用リポジトリの自動クリーンアップが CI 環境でも正しく動作する
- [ ] CI 用の GITHUB_TOKEN に必要な権限（`repo`, `workflow`, `delete_repo`）が文書化されている
