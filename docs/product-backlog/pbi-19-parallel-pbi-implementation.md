# PBI-19: PBI ワークフロースキルに並列実装モードを追加

## ステータス: 未着手

## 依存
- なし

## 説明
レトロスペクティブ（PBI の並列作業 P2）で指摘された「Sub-agent は逐次実行で、複数 PBI の同時実装を行っていない」問題に対応する。

Sprint 1 では 9 PBI を 1 つずつ順番に実装したが、PBI-3/4 のように独立した PBI は並列に sub-agent を起動して同時実装できるはずだった。PBI ワークフロースキルに「並列実装モード」を追加し、依存関係のない複数 PBI を同時に sub-agent 委任できるようにする。

## 受け入れ条件
- [ ] PBI ワークフロースキルに並列実装モードの説明が追加されている
- [ ] 依存関係チェックを行い、並列実行可能な PBI グループを自動判定するロジックがある
- [ ] 並列実行時の競合リスク（同一ファイル変更）に対する注意事項が文書化されている
