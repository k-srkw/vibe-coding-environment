# PBI-20: テンプレートプロジェクトの CI/CD パイプライン追加

## ステータス: 完了

## 依存
- なし

## 説明
レトロスペクティブ（ハーネスエンジニアリング P1 / PBI の並列作業 P3）で指摘された「テンプレートプロジェクト自体に CI/CD がなく、42 テストが自動実行されていない」問題に対応する。

現在、テスト実行は手動の `npm test` に完全に依存している。PR/push 時に自動でテストを実行する GitHub Actions ワークフローを追加し、リグレッション検出を自動化する。

## 受け入れ条件
- [x] `.github/workflows/` にテスト実行ワークフローが追加されている
- [x] push / PR 作成時にテストが自動実行される
- [x] ワークフローで `npm test` が実行され、結果が PR にレポートされる
- [x] テスト失敗時にマージがブロックされる設定ガイドがある

## 受け入れ条件の検証方法
| 受け入れ条件 | 検証方法 | 対応するシナリオ |
|-------------|---------|----------------|
| `.github/workflows/` にテスト実行ワークフローが追加されている | 自動テスト | テスト実行ワークフローファイルが存在する |
| push / PR 作成時にテストが自動実行される | 自動テスト | push 時にテストが自動実行される / PR 作成時にテストが自動実行される |
| ワークフローで `npm test` が実行され、結果が PR にレポートされる | 自動テスト | ワークフローで npm test が実行される / テスト結果が PR にレポートされる |
| テスト失敗時にマージがブロックされる設定ガイドがある | 自動テスト | ブランチ保護ルール設定ガイドが存在する |

## 想定する成果物
- `.github/workflows/test.yml`（テスト自動実行ワークフロー）
- ブランチ保護ルール設定ガイド
