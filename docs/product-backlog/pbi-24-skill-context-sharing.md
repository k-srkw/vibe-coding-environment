# PBI-24: スキル間コンテキスト共有メカニズムの設計

## ステータス: 未着手

## 依存
- なし

## 説明
レトロスペクティブ（コンテキストエンジニアリング P6）で指摘された「スキル間のコンテキスト共有メカニズムがなく、前スキルの出力を次スキルに自動的に引き継げない」問題に対応する。

現在の 3 つのカスタムスキル（product-backlog-guide, pbi-workflow, sprint-retrospective）は独立して動作しているが、SDLC パイプラインとしてはスキル間の連携が必要。例えばレトロスペクティブの Try 項目を backlog-guide に渡す、PBI 完了情報をレトロスペクティブに渡すなど。構造化出力フォーマットを設計し、スキル間の連携を強化する。

## 受け入れ条件
- [ ] スキル間で共有可能な構造化出力フォーマット（JSON または YAML）が定義されている
- [ ] 少なくとも 1 つのスキルペア間でコンテキスト受け渡しが実装されている
- [ ] スキル連携のドキュメントが作成されている
