# PBI-25: skeleton の @types/node バージョンをルートプロジェクトと統一

## ステータス: 未着手

## 依存
- なし

## 説明
Sprint 3 レトロスペクティブで指摘された skeleton の `@types/node` バージョン不一致を解消する。

ルートプロジェクトでは `@types/node: "^26.1.1"` を使用しているが、skeleton では `@types/node: "^22.0.0"` のままになっている。生成プロジェクトが古い型定義に依存することになり、将来的な型不整合リスクがある。

## 受け入れ条件
- [ ] skeleton/package.json の `@types/node` がルートプロジェクトと同じバージョン（`^26.1.1`）に更新されている
- [ ] skeleton の `npm test` が更新後も正常に動作する（動的行動テストで検証）
- [ ] skeleton/package-lock.json が更新されている
